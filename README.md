# 幻想割草：元素幸存者

阶段 3：核心战斗循环已接入。项目仍为纯 HTML + CSS + JavaScript + Canvas 2D，无构建步骤、无第三方运行时依赖、无远程 CDN。

## 阶段 3 已实现

- WASD / 方向键移动，斜向移动归一化，角色不会离开竞技场边界。
- 自动搜索攻击范围内最近的敌人并发射对应初始元素的投射物。
- 普通、快速、精英三类敌人从竞技场边缘刷新，按生存时间分波增强。
- 玩家与敌人接触碰撞、受伤、短暂无敌时间、受击闪光与可关闭的屏幕震动。
- 投射物与敌人碰撞、敌人生命值和受击反馈。
- 敌人死亡掉落经验晶石，并有概率掉落金币；掉落物进入拾取范围后自动吸附。
- 经验升级，升级时小幅提升基础伤害和最大生命。
- 敌人会随机带有短暂的环境元素附着，玩家命中后可与所选元素触发感电、燃烧、超导、蒸发、超载、融化、冻结、绽生、扩散及其他元素共鸣。
- 死亡结算展示生存时间、击杀数、等级、本局获得经验、本局金币和累计金币。
- 结算时保存金币、累计击杀、最佳生存时间和最高等级到 localStorage。
- 再次挑战会清理上局实体并重置局内数据；放弃本局不会发放本局奖励。
- 敌人查询采用简单网格空间分区；投射物、掉落物和粒子使用对象池。

## 操作方式

- `W` / `A` / `S` / `D` 或方向键：移动。
- 角色自动攻击攻击范围内最近的敌人，无需手动按攻击键。
- 右上角暂停按钮或 `Esc`：暂停 / 继续。
- 触屏虚拟摇杆计划在阶段 5 加入；当前战斗移动主要使用键盘。

## 本地测试

推荐在项目根目录启动静态服务器：

```bash
python -m http.server 8000
```

访问 `http://localhost:8000/`。也可以直接双击 `index.html`，但不同浏览器对 `file://` 的 localStorage 行为可能不同。

### 建议自测顺序

1. 点击“开始冒险”，选择任意元素。
2. 使用 WASD / 方向键移动，确认玩家光球移动且不会越过边界。
3. 不移动，等待敌人从屏幕边缘刷新；观察角色自动攻击最近敌人。
4. 观察敌人受击、生命条变化和死亡粒子效果；注意敌人的元素光环。
5. 靠近经验晶石 / 金币，确认掉落物吸附并增加 HUD 经验或金币；不同元素命中同一敌人时观察反应提示。
6. 连续击杀升级，确认等级和经验条更新。
7. 让敌人接近玩家，确认生命减少、受击闪烁和无敌时间。
8. 暂停后等待数秒，确认战斗时间、敌人位置和 HUD 不继续变化；恢复后继续。
9. 站立不动等待死亡，确认结算弹窗出现，时间、击杀、等级和金币正确。
10. 点击“再次挑战”，确认敌人、投射物、掉落物和本局计数已清理。
11. 再次死亡后返回主菜单，刷新页面，确认累计金币和统计已保存。
12. 打开 Console，确认没有脚本异常；在窄屏设备检查 HUD 与结算弹窗是否溢出。

## 存档字段

当前沿用 `fantasy-survivor-save-v1`：

- `gold`：累计金币。
- `stats.lifetimeKills`：累计击杀。
- `stats.bestSurvivalSeconds`：最长生存时间。
- `stats.bestLevel`：最高等级。
- `settings`：音量、粒子和屏幕震动设置。

## GitHub Pages 部署

仓库：`xuanyue129/xuanyue129.github.io`  
入口：`https://xuanyue129.github.io/`

1. 先备份仓库或创建开发分支。
2. 将本项目全部文件覆盖到仓库根目录，保持 `index.html`、`styles.css`、`about.html` 与 `js/` 同级。
3. 保留旧个人主页内容时，先将它迁移到 `about.html`；当前 `about.html` 仍是阶段 2 的占位页面。
4. 提交并推送至 `main`。
5. GitHub 仓库 → Settings → Pages → Deploy from a branch。
6. 选择 `main` 和 `/(root)`，保存后等待部署。
7. 打开 `https://xuanyue129.github.io/` 测试。
