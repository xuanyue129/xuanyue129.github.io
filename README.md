# 米饭的自我救赎 · Stage 6.4

基于原生 HTML、CSS、JavaScript 和 Canvas 的浏览器生存游戏，无需构建工具。适合直接部署到 GitHub Pages。

## 本版内容

- 游戏名称改为 **米饭的自我救赎**。
- 生命采用心数系统：默认 3 颗心，每次有效受击固定扣除 1 颗心。
- 升级卡分为射击、宠物、聚怪、大运四个流派，以及通用词条；词条混合随机出现，不保证玩家每次都能拿到想要的流派。
- 宠物流首次选择「灵伴初现」召唤宠物。宠物环绕角色，随后向目标方向冲撞；同一次冲撞路径上的所有敌人都会受伤。可强化冲撞距离、宽度、宠物数量、冲撞间隔和速度。宠物没有生命值，不会被敌人攻击。
- 聚怪流首次选择「风眼初现」解锁风漩涡，按照射击轮次触发，牵引周围敌人并持续伤害。
- 大运流首次选择「大运临身」解锁受击反噬：玩家受到攻击后，在持续时间内对周围敌人造成伤害。可强化伤害、范围和持续时间。
- 大运流只保留三种生命相关成长：击杀指定数量敌人恢复 1 颗心、生命上限增加 1 颗心、每隔指定时间恢复 1 颗心。其他旧版立即/持续回血词条已移除。
- 金币获取、经验获取、经验与金币吸收范围、移动速度等归入通用词条。
- 手机端增加虚拟摇杆，支持拖动控制角色；电脑端保留 WASD 和方向键。画布按容器尺寸和设备像素比自动调整，支持方向切换和窗口缩放。
- Stage 6.1：手机竖屏进入时显示横屏游玩引导；点击后尝试请求浏览器全屏与横屏锁定（需浏览器支持），不支持时可按提示手动旋转。手机横屏进入战斗后切换沉浸式布局，隐藏站点导航和页脚，HUD 压缩为单行，战斗画布占满屏幕，摇杆尺寸随横屏高度自适应。使用 ResizeObserver、orientationchange、fullscreenchange 和 visualViewport 变化触发画布重设。
- Stage 6.2：手机访问网站时，首页菜单即使用设备完整可视区域，隐藏站点页眉和页脚；进入战斗后 Canvas 与 HUD 延展至横屏视口。虚拟摇杆默认位于右下区域，支持调整位置。摇杆向量算法不变。
- Stage 6.3：大运流派触发的「气运反噬」持续期间完全无敌；气运反噬初始持续时间与风漩涡初始持续时间均调整为 1 秒，后续可通过对应升级词条延长。增加开发测试快捷键：战斗进行中按 `J` 清屏秒杀当前所有敌人（包括 Boss）。
- Stage 6.3：玩家达到 10、20、30……级时触发对应等级的守关 Boss。Boss 入场会清除场上小怪、清理旧子弹并暂停普通刷新；Boss 具有蓄力冲撞、带电屏障和召唤 3 只双倍移动速度紫色精英三种攻击。Boss 拥有独立血条与入场/攻击提示；击败后清除召唤物、掉落奖励并恢复普通刷怪。连续跨过多个十级门槛时会排队依次挑战。
- Stage 6.4：战场改为大地图，玩家移动时摄像机跟随，地图中心区域保持角色居中；抵达地图边缘时摄像机停止越界，绘制明确边界。手机端镜头缩放为 0.66，PC 为 0.84，扩大可视范围、降低角色与怪物在画面中的占比。普通敌人从摄像机可视区域边缘附近进入，避免大地图边缘刷怪导致敌人久不出现。
- Stage 6.4：手机设置中增加轮盘位置预览，玩家可拖动预览轮盘来自定义实际战斗中的触控位置，也可恢复默认位置；位置自动写入本地存档并在不同局次间保留。
- 存档 schema 升级到 v4；旧版本会自动迁移，旧生命商店等级按每 3 级折算为 1 颗心，最多折算为 10 级；新增轮盘位置设置默认值，既有金币、升级和统计不受影响。
- 保留金币商店、转生/声望、离线收益和本地自动存档。永久生命商店每级增加 1 颗初始心。

## 运行

直接在浏览器打开 `index.html`，或将整个目录部署到 GitHub Pages。手机端请横屏游玩：网站打开后首页会铺满手机可视区域；竖屏时显示方向引导，横屏后点击“开始冒险”会尝试请求浏览器全屏与横屏锁定。战斗采用大地图与跟随镜头，角色在地图边缘以内保持在视野中心，抵达边界后相机停止继续移动。手机设置页面的“移动轮盘位置”预览可以拖动轮盘，保存后会应用到战斗界面；默认位于右下侧。浏览器通常不允许网页在未发生用户点击时自行隐藏地址栏或强制进入 Fullscreen API，因此真正隐藏浏览器界面会在玩家点击开始后尝试；iOS Safari 等不支持方向锁定或全屏的环境会保留全视口布局，请手动旋转设备。电脑端使用 WASD / 方向键。
